# 💸 Clone Nubank (App Android)

Este projeto é um clone de algumas funcionalidades do app Nubank, desenvolvido com foco em simular a interface e a experiência de usuário. O objetivo foi praticar desenvolvimento mobile e reproduzir uma interface moderna, intuitiva e funcional.

## 📱 Funcionalidades

- Tela de boas-vindas com saudação personalizada e saldo da conta
- Acesso à área de **Cartões de Crédito**
- Acesso à área **Pix** com funcionalidades:
  - Transferir
  - Programar transferências
  - Ler QR Code
  - Pix Copia e Cola
  - Cobrar
  - Depositar
- Tela de valor para transferência com verificação de saldo
- Tela de seleção de destinatário com contatos frequentes e todos os contatos
- Tela final de confirmação de transferência com dados bancários e opção de mensagem

## 🧪 Tecnologias Utilizadas

- **Java/Kotlin** (dependendo do que você usou)
- **Android Studio**
- **XML** para layouts
- **Material Design** para UI/UX
